# Mellivora Next licensing policy

New copyrightable first-party firmware, Studio IDE and official showcase contributions are intended to be distributed under GNU GPL version 3 only (SPDX: GPL-3.0-only), subject to confirmation of rights and per-file notices. See ../COPYING for the license text.

Existing MIT grants remain valid. The existing LICENSE file is retained to preserve its copyright and permission notices. Do not represent earlier releases or inherited MIT files as exclusively GPL-licensed. The next combined firmware release is intended to be GPLv3, subject to completing the dependency and copyright audit. No release or main-branch relicensing is performed by this policy commit.

Independent SDK templates and application examples may be explicitly permissively licensed where appropriate after reviewing the native module ABI and any needed GPL linking exception. Do not assume that independently distributed modules are automatically exempt. Preserve third-party notices and verify the pinned Pico SDK, networking and crypto dependencies.

Before release: inventory copyright holders, third-party components and license obligations; add accurate per-file SPDX notices; verify corresponding source and build scripts for distributed UF2 images; evaluate installation-information requirements; update README and release metadata; review contribution policy and any separate commercial licensing rights. GPL permits commercial distribution; trademark policy is separate. AGPL is not selected for this embedded firmware.
