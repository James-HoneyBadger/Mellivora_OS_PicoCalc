4Prepare the SD card

The starter pack adds sample BASIC, Tiny C, and Forth programs, user themes, and offline documentation. Copy its contents to a FAT16/FAT32 card.

Download sd_starter_pack.zip Hardware reference User guide
What is on the card?
  • /apps — .mapp modules plus BASIC, Tiny C, and Forth scripts
  • /themes — NAME.thm palettes used by theme NAME
  • /bin — scripts installed by mpkg
  • /apps/repo.json — package index cached by mpkg update

Works offline. Firmware files are parsed with the UF2 block format (magic 0x0A324655, family ID check) and hashed with the Web Crypto API. Nothing is transmitted to a server.

  • Web Serial needs Chrome, Edge, or another Chromium browser and a secure context (https or localhost).
  • Direct-to-drive copying uses the File System Access API; otherwise use your file manager.
  • If the bootloader rejects the file, the board model and UF2 family do not match.
